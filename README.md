# Столовая: меню и предзаказ

**Вариант 22 — учебный Django-проект**

## 1. Описание проекта

Веб-приложение для управления меню столовой и оформления предварительных заказов. Пользователи могут просматривать блюда, добавлять их в корзину и оформлять заказы. Сотрудники и администраторы могут управлять блюдами и просматривать статистику.

## 2. Технологии

- Python 3.14
- Django 6.1
- SQLite
- Django REST Framework
- drf-yasg (Swagger / ReDoc)
- Bootstrap 5
- HTML / CSS
- openpyxl
- python-dotenv

## 3. Основные возможности

- Просмотр меню и блюд.
- Поиск и фильтрация блюд.
- Сортировка и постраничная навигация.
- Регистрация и авторизация.
- Разделение доступа по ролям.
- Создание, просмотр, редактирование и удаление блюд.
- Корзина с изменением количества блюд.
- Подсчёт общей суммы заказа.
- Оформление заказов.
- Статистика и ежедневные отчёты.
- Экспорт данных в Excel.
- REST API для работы с данными проекта.
- Документация API через Swagger и ReDoc.

## 4. Роли пользователей

- **Администратор** — управление блюдами, доступ к статистике и административным функциям.
- **Пользователь** — просмотр меню, добавление блюд в корзину и оформление заказов.

## 5. Входные и выходные данные

**Входные данные:**
- Названия и описания блюд.
- Категории блюд.
- Цены.
- Количество выбранных блюд.
- Имя пользователя и данные для оформления заказа.

**Выходные данные:**
- Список блюд и меню.
- Содержимое корзины и общая сумма.
- Оформленные заказы.
- Статистика и ежедневные отчёты.
- Экспорт данных в Excel.
- Ответы REST API.

## 6. Установка и запуск

1. Клонировать репозиторий:

```bash
git clone https://github.com/nurzhansadykov237-cloud/cafeteria-project.git
```

2. Перейти в папку проекта:

```cmd
cd cafeteria-project
```

3. Создать виртуальное окружение:

```cmd
py -m venv venv
```

4. Активировать окружение:

```cmd
venv\Scripts\activate
```

5. Установить зависимости:

```cmd
pip install -r requirements.txt
```

6. Создать файл `.env` в корневой папке проекта и указать собственный секретный ключ:

```env
SECRET_KEY=ваш_секретный_ключ
DEBUG=True
```

Для генерации секретного ключа можно выполнить команду:

```cmd
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

Полученный ключ нужно скопировать в `.env` вместо `ваш_секретный_ключ`.

**Важно:** файл `.env` не следует публиковать на GitHub.

7. Выполнить миграции:

```cmd
python manage.py migrate
```

8. Загрузить начальные данные:

```cmd
python manage.py loaddata core/fixtures/seed_data.json
```

Команда добавит в базу подготовленные записи: категории, блюда и меню дня.

9. Создать администратора:

```cmd
python manage.py createsuperuser
```

10. Запустить сервер:

```cmd
python manage.py runserver
```

11. Открыть сайт:

`http://127.0.0.1:8000/`

## 7. API и документация

- API: `http://127.0.0.1:8000/api/`
- Swagger: `http://127.0.0.1:8000/api/docs/`
- ReDoc: `http://127.0.0.1:8000/api/redoc/`

API предназначен для работы с данными приложения. Доступ к операциям ограничивается правами пользователя.

## 8. Запуск автоматических тестов

Для запуска тестов выполнить:

```cmd
python manage.py test core
```

В проекте реализовано 19 автоматических тестов для проверки моделей, форм, представлений, API и корзины.

## 9. Структура проекта

- `config/` — настройки Django и маршрутизация.
- `core/` — основное приложение.
- `core/models.py` — модели базы данных.
- `core/views.py` — представления и API.
- `core/forms.py` — формы и валидация.
- `core/tests.py` — автоматические тесты.
- `core/templates/core/` — HTML-шаблоны.
- `core/migrations/` — миграции базы данных.
- `core/fixtures/` — начальные данные проекта.
- `docs/` — документация и схемы проекта.
- `requirements.txt` — зависимости проекта.
- `.env` — локальные настройки и секретный ключ.
- `logs/` — журналы ошибок.
- `manage.py` — управление Django-проектом.
