# Столовая: меню и предзаказ

**Вариант 22 — учебный Django-проект**

## Описание проекта

Веб-приложение для управления меню столовой и оформления предварительных заказов. Система позволяет просматривать блюда, выбирать позиции меню, оформлять заказы и управлять данными столовой.

## Технологии

- Python 3.14
- Django 6.1
- SQLite
- Django REST Framework
- drf-yasg (Swagger / ReDoc)
- Bootstrap 5 (планируется)
- openpyxl

## Основные возможности

- Просмотр меню и блюд.
- Поиск блюд и фильтрация по категориям.
- Сортировка и постраничная навигация.
- Регистрация и авторизация пользователей.
- Разделение доступа по ролям.
- Добавление, просмотр, редактирование и удаление блюд.
- Оформление заказов.
- Статистика и ежедневные отчёты.
- Экспорт данных в Excel.
- REST API для блюд, меню и заказов.
- Документация API через Swagger и ReDoc.

## Роли пользователей

- **Администратор** — управление блюдами и доступ к административным функциям.
- **Пользователь** — просмотр меню и оформление заказов.

## Установка и запуск

1. Клонировать репозиторий.
2. Перейти в папку проекта.
3. Создать виртуальное окружение:

```bash
python -m venv venv
```

4. Активировать окружение в Windows:

```cmd
venv\Scripts\activate
```

5. Установить зависимости:

```bash
pip install -r requirements.txt
```

6. Выполнить миграции:

```bash
python manage.py migrate
```

7. Запустить сервер:

```bash
python manage.py runserver
```

8. Открыть в браузере:

`http://127.0.0.1:8000/`

## API и документация

- API: `http://127.0.0.1:8000/api/`
- Swagger: `http://127.0.0.1:8000/api/docs/`
- ReDoc: `http://127.0.0.1:8000/api/redoc/`

## Запуск тестов

```bash
python manage.py test core
```

## Структура проекта

- `config/` — настройки Django и маршрутизация.
- `core/` — основное приложение.
- `core/models.py` — модели базы данных.
- `core/views.py` — представления и API.
- `core/forms.py` — формы.
- `core/tests.py` — автоматические тесты.
- `templates/` — HTML-шаблоны.
- `requirements.txt` — зависимости проекта.
- `manage.py` — запуск и управление Django.
