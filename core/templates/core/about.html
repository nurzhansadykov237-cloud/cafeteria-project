О проекте

Столовая: меню и предзаказ

Это учебный веб-проект, разработанный на языке Python с использованием фреймворка Django.

Назначение проекта

Система предназначена для просмотра меню столовой, выбора блюд и оформления предварительных заказов.

Основные возможности
  • Просмотр меню и категорий блюд.
  • Поиск, фильтрация и сортировка блюд.
  • Регистрация и авторизация пользователей.
  • Разграничение прав доступа.
  • Создание, редактирование и удаление блюд.
  • Оформление предварительных заказов.
  • Статистика и отчёты по заказам.
  • REST API и документация Swagger.
Технологии
  • Python
  • Django
  • Django REST Framework
  • SQLite
  • Bootstrap 5
  • HTML и CSS
